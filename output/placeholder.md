This folder contains index files computed from the SBA PPP loan-level data using the R scripts in this repository.

## Gender Gap Indices

| File | Year | Description |
|------|------|-------------|
| `2020_final.xlsx` | 2020 | Four gender gap indices by state: Representation Gap, Access Gap, Loan Size Gap, and Early Access Gap |
| `2021_final.xlsx` | 2021 | Four gender gap indices by state: Representation Gap, Access Gap, Loan Size Gap, and Early Access Gap |

Each file contains 51 rows (50 states + DC) and four index columns computed in `4_Indices.R`.
